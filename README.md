# SAHAKAR

A frontend concept experience for the Paytm AI Hackathon, Merchant Growth AI track. The landing page tells a merchant story and includes an eight chapter interactive walkthrough of the proposed product.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## What the demo covers

- Digital storefront, products, inventory, social orders, and Paytm payment flow
- Policy-aware AI support and verified ticket escalation
- Digital khata, outstanding payments, and reminders
- Sales insights, customer re-engagement, personalized offers, and loyalty concepts
- Government scheme discovery and eligibility guidance
- Saha, the AI business agent, shown through a scripted sample input

All interactions use illustrative sample data. The project has no backend, external integrations, real payments, or live AI calls.
